Comece uma issue neste repositório: $ARGUMENTS

1. Leia `CLAUDE.md` deste diretório e só os arquivos que a issue toca.
2. Escreva um plano de no máximo 6 passos, cada um com a prova que o fecha (comando ou script).
3. Se a issue mexe em `db/schema.ts`, inclua `npm run db:generate` e a migração nova no plano.
4. Execute o plano. Depois de cada passo, rode a prova dele antes de seguir.
5. Ao terminar, rode `/issue-verify`.
